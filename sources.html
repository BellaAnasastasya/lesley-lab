Sumber & batas data

Lesley Lab L1 · dibuat 5 November 2026. Aplikasi penggemar; tidak berafiliasi dengan MOONTON.

  • 133 profil hero: data dan traits dari Miya Lab dan Gord Lab yang dilampirkan pengguna. Nama dan mekanik mewarisi snapshot contoh; bukan daftar hero yang diperbarui langsung dari server game.
  • Logika Lesley ditulis ulang: core Berserker’s Fury, Endless Battle, Blade of Despair; sepatu dan dua slot adaptif. Skor membaca musuh dan teman, tanpa asumsi inventori aktual.
  • Halaman resmi Lesley: rujukan identitas hero. Halaman dinamis tidak memberikan seluruh angka skill melalui pembaca teks, sehingga aplikasi tidak mengklaim simulasi damage atau angka patch terbaru.
  • MLBBHub Lesley: referensi pola critical burst, urutan core, spell dan alternatif situasional. Build akhir dalam aplikasi merupakan hasil heuristik lokal, bukan build yang diambil langsung dari situs.
  • Repositori Ceplin03: file PNG hero dan equipment asli game. Emblem, talent, serta spell diunduh dari direktori gambar MLBBHub. Semua gambar dibundel lokal; tidak ada placeholder SVG atau hotlink saat pemakaian.
  • Daftar sumber setiap gambar mencatat URL dan nama file untuk audit. Hak cipta artwork tetap milik pemilik aslinya, termasuk MOONTON.

Perubahan patch dapat mengubah atribut item/skill. Periksa deskripsi dalam game. App ini sengaja tidak menampilkan DPS, harga, atau agregat stat yang tidak bisa dijamin cocok dengan patch aktif.

Offline: service worker menyalin seluruh daftar berkas aplikasi, termasuk semua gambar, sebelum menyatakan siap. Browser/iOS tetap dapat menghapus data karena ruang penyimpanan atau penghapusan data situs. Setelah cache terhapus, diperlukan internet untuk mengunduh lagi.
